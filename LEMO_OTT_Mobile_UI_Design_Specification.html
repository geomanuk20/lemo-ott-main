Section 03
Component Engineering & Screen Deep Dive
Technical implementation of core application screens
🎬 Custom HLS Video Player (PlayerScreen.js)
High-performance video streaming with expo-av and HLS master manifest playback.
  • Adaptive Streaming: Auto quality selection from 360p up to 4K Ultra HD.
  • Gesture Controls: Double tap left/right for ±10s seek with ripple animation.
  • Smart Ad Injection: Pre-roll and mid-roll advertisement engine with non-skippable countdown timer.
  • Binge-Watch Mode: 10-second auto next episode countdown with direct cancel/play action.
  • Rating Submission: Native 5-star interactive rating modal with backend sync.
📱 Vertical Shorts Engine (ShortsScreen.js)
Full-screen vertical paging feed with auto memory management.
  • Viewability Auto-Play: Only the active centered short renders video; adjacent items unmount to conserve GPU memory.
  • Engagement Actions: Double-tap heart burst with optimistic like count increments.
  • Auth Gate Protection: Unauthenticated users prompted with custom sign-in modal on like/save.
  • Direct Details Bridge: 'Watch Full Movie/Series' deep-link direct to DetailsScreen.
ℹ️ Adaptive Details (DetailsScreen.js)
Dynamic UI adapting between Short Films, Movies, and Shows.
  • Zero Redundancy: Episode accordions hidden for single-play films.
  • Watchlist Engine: Instant bookmark state with optimistic UI caching.
  • Premium Gate: Paid content routes users to Subscription Checkout.
🔥 Pocket Reels Grid (PocketReelsScreen.js)
2-column micro-drama discovery grid with episode counters.
  • Hero Spotlight: Featured trending drama banner with Instant Ep 1 Play CTA.
  • Episode Counters: Total episodes pill and Free/VIP tier badges.
  • Drama Genre Filters: Romance, Revenge, Suspense, Comedy pill bar.
💳 Monetization & Billing (SubscriptionScreen.js)
Tiered plan cards with multi-gateway checkout.
  • Active Plan Detection: Badges active plan & disables duplicate buy.
  • Coupon Engine: Instant verification with discount math in Checkout.
  • Security: 256-bit SSL encrypted badges to maximize checkout trust.
🛡️ Robustness, Fault Tolerance & 0-Crash Native Architecture
Type-Safe Accessibility Props
All disabled props wrapped in Boolean(...). Prevents native RCTView Android casting crashes from falsy empty strings.
Full-Screen Offline Modal
Dedicated OfflineView modal isolated from headers and tab bars with automatic network reconnection listener and animated retry.
Dynamic Header Sanitization
Content sanitizers automatically strip duplicated headings in Static Pages and deduplicate repeated sections across the home feed.

🧭 Content Discovery & Playback Flow
  • Step 1: User browses Dynamic Home Sections or filters Short Films by Genre & Language.
  • Step 2: Clicks Media Card → Navigates to DetailsScreen with backdrop trailer preview.
  • Step 3: Clicks 'Watch Now' CTA → If Free: opens PlayerScreen with pre-roll ad.
  • Step 4: If Premium content: checks active subscription → redirect to SubscriptionScreen if unverified.
💎 Subscription & Upgrade Flow
  • Step 1: User selects plan (Basic / Standard / VIP Premium) in SubscriptionScreen.
  • Step 2: Moves to CheckoutScreen → optional Promo Code application with real-time math.
  • Step 3: Initiates Secure Gateway → payment verification webhook updates MongoDB user record.
  • Step 4: Instant upgrade receipt → full ad-free 4K streaming unlocked immediately.
